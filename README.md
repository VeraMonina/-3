# Сравнение предсказаний слов людьми и большими языковыми моделями в Cloze-тесте

**Методология сравнения вероятностных распределений на лексическом, синтаксическом и семантическом уровнях.**

Этот репозиторий содержит код и данные для исследования, выполненного в рамках курсовой работы студентки 3 курса ОП «Фундаментальная и компьютерная лингвистика» НИУ ВШЭ Мониной Веры Евгеньевны.

 **Полный текст работы**: [`курсовая 3 курс.pdf`](курсовая%203%20курс.pdf)

## О проекте

В отличие от классических подходов, сравнивающих только точечные предсказания (попадает ли модель в целевое слово), данная работа предлагает **сравнение полных вероятностных распределений** человека и LLM.

### Ключевые вопросы исследования:
- Насколько распределение вероятностной массы в LLM соответствует человеческому?
- Совпадают ли ожидания на грамматическом и семантическом уровнях?
- Могут ли LLM заменить людей при сборе психолингвистических норм?

### Использованные модели:
- **GPT-4o-mini** (через API)
- **Llama 3.1**

### Материал:
- Russian Sentence Corpus (144 предложения, сбалансированных по длине, частотности и части речи целевого слова)
- Cloze-нормы от носителей русского языка (Laurinavichyute et al., 2019)

## Методология

### Извлечение распределений
Модифицированный алгоритм **beam search** без отсечения по вероятности:
- Итеративное расширение всех top-k кандидатов
- Остановка при достижении границы слова или 8 токенов
- Сохранение полных логарифмических вероятностей

### Уровни анализа

| Уровень | Метрики |
|---------|---------|
| **Лексический** | Overlap@k (поверхностные формы и леммы) |
| **Синтаксический** | POS_intersection@k, корреляция POS-распределений, кросс-корреляционный анализ, анализ морфологических признаков (падеж, число, род, время, вид, одушевлённость) |
| **Семантический** | Centroid Similarity (косинусное сходство центроидов), Precision/Recall/F1 на основе эмбеддингов word2vec |
| **Анализ контекста** | Влияние энтропии контекста (квартильный анализ), предсказуемость морфологических параметров целевого слова |

### Инструменты разметки
- **Stanza** (Universal POS Tags)
- **PyMorphy3** (OpenCorpora)

## Основные результаты

### 1. Лексический уровень
- **GPT-4o-mini**: overlap@k быстро выходит на плато (≈25-26%)
- **Llama**: достигает 49% при top-400, но ценой широкого распределения
- Overlap по леммам выше, чем по поверхностным формам → расхождения связаны с морфологией, а не с выбором лексемы

### 2. Синтаксический уровень
| Показатель | GPT | Llama |
|------------|-----|-------|
| POS_intersection@1 (наиболее вероятная часть речи) | 0.69 | 0.38 |
| Корреляция для NOUN (r) | 0.693 | 0.194 |
| Корреляция для ADP (предлоги, r) | 0.830 | ~0 |
| Причастия и деепричастия | не воспроизводятся | не воспроизводятся |

### 3. Семантический уровень
- **GPT**: F1 ≈ 0.43 (компактное, точное распределение)
- **Llama**: F1 ≈ 0.06 (широкое, но неточное)
- Centroid Similarity: GPT ≈ 0.70, Llama ≈ 0.37 (при top-100)

### 4. Анализ контекста
- С ростом энтропии контекста (открытости) лексическое перекрытие снижается у обеих моделей
- Люди превосходят обе модели по предсказанию морфологических признаков целевого слова
- GPT лучше воспроизводит глагольные категории (вид, время), Llama — падеж
